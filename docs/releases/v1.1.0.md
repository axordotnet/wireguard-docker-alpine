# v1.1.0

- Alpine 3.24.4, daily dependency checks and uncached security rebuilds.
- Read-only root filesystem and reduced runtime capabilities.
- Explicit auto/kernel/userspace implementation selection; native and wireguard-go
  tunnels tested over IPv4 and IPv6, including stop/restart recovery.
- Optional route-checked ICMP healthcheck; default checks interface presence only.
- Tested/scanned image digest promoted with SBOM and provenance.
- MIT license, security/contribution policies and English documentation.

## Upgrade and rollback

Review custom hooks for writes incompatible with the read-only filesystem.
NET_ADMIN and DAC_READ_SEARCH are used; optional ICMP probing also needs NET_RAW.
Save the current running image digest before pulling this version. Recreate the
container in a maintenance window. To roll back, set image to the saved digest
and recreate the container; keep the original VPN configuration unchanged.

Linux/amd64 only. Validated in GitHub CI, not on AXORLOGY or Synology DSM.
No production host deployment is performed.
